# Ранковий випуск: інструкція для хмарного завдання

Ти щоранку наповнюєш додаток «Ранкове читання» (файл `articles.json` у цьому репозиторії).

1. Прочитай `topics.json`: теми, кількість статей на тему, мови.
2. Для кожної теми знайди в інтернеті свіжі статті й дописи з блогів, опубліковані за останні 24–48 годин.
   - Бери лише справжні статті з робочими посиланнями, які ти відкрив і прочитав. Нічого не вигадуй.
   - Уникай новинних дайджестів-клонів, реклами, платних статей без доступу.
   - Пропусти статті, чиї `url` вже є в `articles.json`.
   - Якщо WebFetch не може відкрити сайт (помилка `ENOTFOUND` чи інша мережева), НЕ зупиняйся і не повторюй спроби для цього сайту.
     Тоді беріть статтю прямо з результатів WebSearch (режим `extended` для свіжості), якщо там є точний URL статті
     (не головна сторінка, не RSS, не агрегатор) і з назви/сніпета видно, що вона свіжа. Опис пиши лише за тим,
     що є в результатах пошуку, без вигаданих деталей. Випуск без жодної статті — лише якщо пошук справді нічого не дав.
   - Якщо в темі є `sources`, спершу перевір ці сайти (офіційні блоги), потім шукай деінде.
   - Якщо в темі є `favoriteTeam`, щонайменше половина статей теми — про цю команду.
3. Для кожної статті напиши `summary` українською: 2–3 речення, про що вона і чим цікава.
4. Додай на початок масиву `days` новий день:
   ```json
   { "date": "РРРР-ММ-ДД", "articles": [
     { "title": "…", "url": "https://…", "source": "домен", "topic": "назва теми з topics.json",
       "lang": "uk|en|…", "summary": "…" } ] }
   ```
   `title` — українською (переклади, якщо оригінал іншою мовою). Онови `updated` (ISO-час).
5. Очищення: залиш у `days` лише останні 7 днів (за `date`), старіші видали повністю.
6. Перевір, що `articles.json` — валідний JSON, зроби коміт `Ранковий випуск РРРР-ММ-ДД`, виконай `git pull --rebase origin main` і запуш у гілку `main`.
